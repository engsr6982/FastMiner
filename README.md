# FastMiner

一个基于 Levilamina 的快速连锁采集 Mod，支持 Server 和 Client 双端运行。

## 🧭 双端功能差异（请先阅读）

FastMiner 的 Client 端与 Server 端是**两种能力不同的版本**，安装组合对应不同体验：

|                                                     | 客户端侧模组 (Client)                                                                                                   | 服务端侧插件 (Server)                     |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| 适用场景                                            | 本地世界 / 局域网主机                                                                                                   | BDS 服务器（对全服生效）                  |
| 需要对方配合？                                      | 不需要，单机即可用                                                                                                      | 不需要客户端 mod 也能用                   |
| 连锁挖掘核心                                        | ✅ 按住 V 直接连锁                                                                                                      | ✅ 全服玩家均可使用（需开启对应方块）     |
| 成本 / 经济扣费                                     | ❌ 无                                                                                                                   | ✅ 支持 LLMoney / 计分板经济与计费        |
| 白名单 / 工具 / 精准采集限制                        | ❌ 无                                                                                                                   | ✅ 支持方块白名单、工具限制、精准采集策略 |
| **连锁范围透视预览**（按住 V 显示待挖方块外壳轮廓） | ✅ **客户端侧独有**                                                                                                     | ❌ 无                                     |
| 配置界面                                            | ✅ /fm 方块配置 GUI                                                                                                     | ✅ /fm 方块管理 GUI（OP）                 |
| 双端同装时                                          | 客户端 mod 提供**透视预览 + 本地快速连锁**；服务端插件提供**规则与经济计费**；服务端命令/配置覆盖客户端（以服务端为准） |                                           |

## 客户端侧模组安装 (Client Side)

此版本适用于本地游玩使用，为原版生存添加便利：按住 V 键即显示连锁范围预览并直接连锁采集，开箱即用。

> 注意：此版本**无法在纯远程服务器上使用连锁**（须为局域网主机或进入本地世界）。

```bash
lip install github.com/engsr6982/FastMiner#client
```

> Tip: 按住 V 键挖掘方块即可连锁（默认绑定 V 键，可在配置文件更改）。按住时准星指到的方块会显示**连锁范围外壳轮廓**，方便预估挖掘范围。

### 功能特性（客户端独有）

- **连锁范围透视预览**：按住 V 显示待挖区域外壳轮廓，方便预估挖掘范围
- 按住 V 时搜索范围跟随准星实时更新；破坏锚点方块后按预览范围开始连锁
- 全部渲染仅本机可见，不影响多人联机体验（局域网 / 本地世界）

### 命令

- /fm 打开方块配置GUI - 配置覆盖方块

### 配置文件

```json
{
  "version": 4,
  "dispatcher": {
    "globalBlockLimitPerTick": 256, // 全局每刻连锁上线
    "maxResumeTasksPerTick": 16 // 每刻恢复任务上限
  },
  "bindKey": 86, // 绑定按键 (Windows VK Code)

  // 连锁范围透视描边配置
  "outline": {
    "enabled": true, // 描边总开关（false 关闭预览）
    "maxBlocks": 1024, // 描边数量上限（防止超大连锁范围拖慢渲染）
    "searchPerTick": 256 // 预搜索每 tick 配额
  },

  // 全局默认配置，当按下快捷键进行破坏时，如果没有找到覆盖配置
  // 将会使用此默认配置进行进行连锁任务
  "blockDefault": {
    "name": "全局默认配置",
    // "limit": 256, // 最大连锁采集数量 (可选, 默认 1024)
    "destroyMode": "Default", // 破坏模式，支持: Default 和 Cube。 Default搜索相邻的6个面，Cube 3x3x3搜索
    "similarBlock": [] // 不用填
  },

  // 方块覆盖配置
  // 你可以在这里调整特定方块的行为，做到针对性覆盖默认配置
  // 比如: 金合欢树长的歪七扭八，默认配置的相邻搜索默认容易遗漏方块，您就可以在这里重写为 3x3x3 Cube 搜索模式
  "overrides": {
    // 方块配置，Key 填写方块命名空间
    "minecraft:spruce_log": {
      "name": "云杉木原木", // 方块名称
      "destroyMode": "Default", // 破坏模式，支持: Default 和 Cube。 Default搜索相邻的6个面，Cube 3x3x3搜索
      "similarBlock": [] // 相似方块，填写方块命名空间，连锁时会一起采集
    },
    "minecraft:birch_log": {
      "name": "白桦木原木",
      "limit": 200, // 最大连锁采集数量(可选字段)
      "destroyMode": "Default",
      "similarBlock": []
    }
  }
}
```

## 服务端侧插件安装 (Server Side)

此版本适用于 BDS 服务器使用，为整个服务器的玩家提供连锁采集功能：无需玩家安装任何客户端模组，服务端统一管理方块白名单、工具限制、精准采集策略与经济计费。若玩家额外安装了客户端侧模组，则额外获得连锁范围透视预览（服务端配置仍覆盖客户端配置）。

> 此版本无法在客户端侧加载，客户端请使用客户端侧模组
>
> 当客户端同样安装了客户端侧模组时，服务端侧的命令会覆盖客户端侧的命令

```bash
lip install github.com/engsr6982/FastMiner
```

> Tip：初次使用，需输入命令 /fm 打开 GUI，开启需要连锁的方块。

### 功能特性（服务端独有）

- 服务端权威调度：全服玩家连锁任务由服务端统一排队、限流与计费，客户端无需任何依赖
- 方块级规则：白名单启用、连锁上限、工具限制、精准采集策略（禁止 / 需要 / 不限）
- 经济接入：LLMoney / 计分板，按方块消耗货币
- 与客户端 mod 共存：客户端提供透视预览与本地连锁，服务端提供规则与经济计费，配置冲突以服务端为准

### 命令

- /fm 打开设置 GUI
- /fm off 关闭连锁采集
- /fm on 开启连锁采集
- /fm manager 方块管理 GUI（OP） 配置方块白名单和经济等

### 配置文件

```json
{
  "version": 6,
  "dispatcher": {
    "globalBlockLimitPerTick": 256, // 每次调度最多采集多少个方块
    "maxResumeTasksPerTick": 16 // 每次调度最多恢复多少个任务
  },
  "moneys": {
    "Enable": false, // 是否启用经济系统
    "MoneyType": "LLMoney", // 经济类型 LLMoney 或 ScoreBoard
    "MoneyName": "money", // 经济名称
    "ScoreName": "" // 计分板名称
  },
  "blocks": {
    // 方块配置，键(Key) 填写方块命名空间
    "minecraft:acacia_log": {
      "name": "金合欢木原木", // 方块名称
      "cost": 0, // 每个方块消耗的经济
      "limit": 256, // 最大连锁采集数量
      "destroyMod": "Cube", // 破坏模式，支持: Default 和 Cube。 Default搜索相邻的6个面，Cube 3x3x3搜索
      "silkTouschMod": "Unlimited", // 精准采集附魔，Unlimited 无限制、Forbid 禁止精准附魔、Need 需要精准附魔
      "tools": [
        "minecraft:wooden_axe", // 工具限制，如果留空数组，则代表不限制工具类型
        "minecraft:stone_axe",
        "minecraft:iron_axe",
        "minecraft:diamond_axe",
        "minecraft:golden_axe",
        "minecraft:netherite_axe"
      ],
      "similarBlock": [] // 相似方块，填写方块命名空间，连锁时会一起采集
    }
  }
}
```
